# stitchipv4

Stitch timestamps and ipv4 durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/stitchipv4/

## Install / run

```bash
git clone https://github.com/theworker02/stitchipv4.git
cd stitchipv4
node src/cli.js
node --test
```
